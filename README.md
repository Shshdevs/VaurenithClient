# VaurenithWeb

**VaurenithWeb** — браузерный интерфейс персональной среды управления разработкой и инфраструктурой Vaurenith. Он помогает управлять проектами и связанными ресурсами, работать с данными облачной платформы и просматривать состояние инфраструктуры.

Продукт развивается с проектно-ориентированным подходом: репозитории, окружения, устройства, контейнеры и сервисы связываются в единое рабочее пространство. Операции с Git, SSH, Docker и локальными ресурсами выполняются через предусмотренные backend-интеграции и клиентские узлы.

Основной стек: React, TypeScript, Vite и pnpm.

## Локальный запуск

Требуются Node.js 22.22.2 и pnpm 12.18.0. Версия Node.js указана в `.nvmrc`.

1. Установи зависимости:

   ```sh
   pnpm install
   ```

2. Создай локальный `.env` на основе примера:

   ```sh
   cp .env.example .env
   ```

   `PORT` задаёт порт dev-сервера и preview; если он не указан, используется порт Vite. `VITE_API_BASE_URL` задаёт базовый URL Backend API; пустое значение направляет запросы на тот же origin. Не помещай секреты в `VITE_*`: эти значения попадают в клиентскую сборку.

3. Запусти dev-сервер:

   ```sh
   pnpm dev
   ```

4. Перед отправкой изменений запусти проверки и production-сборку:

   ```sh
   pnpm check
   pnpm build
   ```

5. Для локального просмотра production-сборки:

   ```sh
   pnpm preview
   ```

Архитектурные слои, правила импортов и границы интеграции с Backend описаны в [документации по архитектуре](docs/architecture.md).
